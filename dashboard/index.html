What you are looking at

This is a live security system I built and run on AWS. A honeypot, a decoy server that looks vulnerable, so every visitor is an attacker, collects real attacks from the internet. A detection engine checks logs from the server, the honeypot and AWS against 18 rules mapped to MITRE ATT&CK. Everything below is real data, refreshed every 5 minutes.
